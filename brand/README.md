# Brand assets

- `iaic-logo.svg` — IAIC organization mark (source vector; dark cosmo squircle, purple "IAIC").
- `iaic-logo-512.png` — 512×512 render (GitHub org avatar / general use).

Regenerate the PNG from the SVG (uses `sharp` from `../scripts`):

```bash
cd ../scripts && npm install && node generate-iaic-logo.mjs
```
